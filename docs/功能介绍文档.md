## 录制注意事项

- 使用清晰的游戏分辨率，避免任务追踪区域被游戏内面板遮挡。
- 演示 WGC 无法取图或不兼容时，可切换为 PrintWindow；无需展示失败过程。
- 粘贴验证时使用空白记事本即可，不要展示个人信息或账号信息。
- 若首次运行需要下载 OCR 模型，建议在正式录制前完成下载。
