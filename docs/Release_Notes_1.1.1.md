# GuoLingZhuShou v1.1.1

国令助手是一款用于识别《QQ 三国》“国令慕贤”任务物品要求的 Windows 桌面工具。选择游戏窗口后，可自动定位任务追踪区域、识别所需物品并复制到剪贴板。

## 本次更新

- 修复无控制台 EXE 首次下载 OCR 模型时可能直接识别失败的问题。
- 新增怪物词表查询：可按怪物名称、等级、出没地点或掉落物离线检索，并可一键复制怪物名称。
- 内置 361 条 QQ 三国官网公开怪物资料。
- 保存截图方式、实时识别间隔、全局快捷键和已选游戏窗口；重新打开程序后自动恢复。
- OCR 模型缓存改为固定保存至用户本地数据目录，避免单文件 EXE 重启后重复下载模型。
- 优化任务物品纠错逻辑，降低相近文字被错误替换的概率。

## 使用说明

1. 下载并运行 `GuoLingZhuShou-1.1.1.exe`。
2. 在“游戏窗口”中选择 QQ 三国窗口，点击“截取窗口”。
3. 点击“识别并复制”，或使用已设置的全局快捷键。
4. 点击“怪物词表”可打开离线怪物资料查询。

首次使用 OCR 时需要联网下载中文识别模型；完成后模型会保存在本地。
