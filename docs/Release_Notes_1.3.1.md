# GuoLingZhuShou v1.3.1

国令助手新增了与 OCR 功能共用同一程序窗口的“窗口闪烁提醒”。当 QQ 三国或其他指定窗口在任务栏闪烁时，工具会播放提示音。

## 本次更新

- 在主界面工具栏新增“闪烁提醒”入口。
- 支持按窗口标题关键字或指定窗口句柄筛选提醒目标。
- 支持系统提示音、自定义 WAV 文件和蜂鸣音。
- 支持设置每个窗口的提醒冷却时间，避免同一事件重复播放声音。
- 重整提醒窗口和主界面工具栏布局，长窗口标题与主要操作按钮在默认尺寸下不再被截断。
- 提醒设置会保存到 `%LOCALAPPDATA%\GuoLingZhuShou\settings.json`。
- 高密度系统事件采用固定容量缓存与分批处理，避免无关窗口活动持续占用内存。

## 使用方式

1. 在主界面点击“闪烁提醒”。
2. 选择要监听的窗口，或点击“使用当前游戏窗口”。
3. 选择声音和冷却时间；窗口打开后会自动开始监听。
4. 点击“测试声音”确认当前声音配置可用。

## 说明

本功能基于 Windows ShellHook 和辅助 WinEvent 事件。部分第三方程序可能不会向系统发送窗口闪烁事件，因此不会产生提醒。
