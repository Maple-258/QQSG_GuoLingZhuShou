# GuoLingZhuShou v1.3.6

## 本次更新

- 主界面新增游戏风格“物品行情”区域：选择区服并输入物品名，即可查看摊位、商行和寄卖行情。
- 查询结果会展示物品名*数量、卖家、摊位/商行信息、位置和单价；完成国令 OCR 后，物品名称会自动带入。
- 账号授权、默认区服和退出登录移至独立的“行情设置”窗口。
- 密码仅用于当前登录请求，不会写入本机配置。账号、登录令牌和区服用于后续查询复用；“退出登录”可立即清除本机令牌。

## 使用说明

- 此功能不需要第三方网站的管理权限，只需该网站的普通账号。
- 行情数据、坐标准确性和服务可用性由第三方网站负责；查询失败时可使用窗口中的“打开原网站”按钮核对。
