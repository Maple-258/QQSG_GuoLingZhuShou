# GuoLingZhuShou v1.2.0

国令助手是一款用于识别《QQ 三国》“国令慕贤”任务物品要求的 Windows 桌面工具。选择游戏窗口后，可自动定位任务追踪区域、识别所需物品并复制到剪贴板。

## 本次更新

- 新增“自定义词库”：可手动添加官网未收录的任务物品名称。
- 仅添加正确名称时，程序会将其纳入安全的单字符 OCR 纠错匹配。
- 可额外填写常见的 OCR 误识名称，建立“误识名称 → 正确名称”精确纠错规则。
- 自定义词库会保存在本地，重新启动后仍然有效。

## 使用方式

1. 点击主界面的“自定义词库”。
2. 输入“正确名称”并点击“添加 / 更新”。
3. 如果 OCR 误识与正确名称差异较大，同时填写“OCR 误识名称”。
4. 保存后无需重启，下一次识别立即使用新词库。
