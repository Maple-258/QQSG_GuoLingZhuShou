# 国令助手

国令助手（GuoLingZhuShou）是一款识别《QQ 三国》“国令慕贤”任务物品要求，并自动复制结果到剪贴板的 Windows 桌面工具。

> 本项目为非官方工具，主要用于学习和研究，并按 [MIT License](LICENSE) 开源。使用者应自行遵守适用的法律法规、游戏规则及服务条款，并承担相应风险与责任。

## 功能

- 自动定位任务追踪区域并识别所需物品。
- 支持 WGC 和 PrintWindow 两种窗口截图方式。
- 支持内置及自定义物品词库纠错、实时识别和自定义全局快捷键。
- 可选云端 PaddleOCR API 识别模式；启用后无需加载本地 PaddleOCR 模型，可降低程序常驻内存。
- 支持多步任务进度追踪：OCR 可识别当前角色、任务和步数，并按角色保存“修行之途”“元神修行”等任务记录；“200步任务”会自动归并为“修行之途”。
- 内置窗口闪烁声音提醒，可按窗口标题或指定窗口筛选，并支持系统提示音、WAV 和蜂鸣音。
- 内置官网怪物资料词表，可按怪物名、等级、地点或掉落物离线查询。
- 主界面内置游戏风格行情查询，可按区服和物品名查看摊位、商行、寄卖记录，以及数量、卖家、位置和单价；支持 OCR 后自动查询和 Enter 查询。
- 内置版本信息、更新日志和 GitHub Release 更新检查。

启动时会默认显示更新日志；可在窗口底部勾选“启动时不再显示”关闭此行为。

## 使用

1. 前往 [Releases](https://github.com/Maple-258/QQSG_GuoLingZhuShou/releases/latest) 下载最新的 `GuoLingZhuShou-*.exe`。
2. 双击 EXE 启动国令助手。
3. 选择游戏窗口，截取窗口后点击“识别并复制”。

本地模式首次 OCR 需要网络连接以下载中文模型。若要使用云端模式，请在“工具与设置 → 云端 OCR 设置”中选择云端模式并自行填写 API 令牌；如使用官方新版 PaddleOCR 服务，还需将该服务页面生成的 API 地址填入“新版 API 地址”。待识别截图会上传至对应 OCR 服务，令牌仅保存在本机设置中。若本地模型已经加载，切换后重启助手可释放原模型占用的内存。

行情查询需要用户自行注册并登录第三方网站的普通账号。密码只会用于当次登录，不会保存到本机；可通过“退出登录”清除本机保存的登录令牌。第三方网站的数据准确性和服务可用性由该网站负责。
