# 国令慕贤任务识别

用于识别《QQ 三国》“国令慕贤”任务追踪中的物品要求，并将识别结果复制到系统剪贴板的 Windows 桌面工具。

> 本项目为非官方工具，与腾讯及《QQ 三国》运营方不存在隶属、授权或合作关系。

## 功能概览

- 从指定游戏窗口获取画面，支持 Windows Graphics Capture（WGC）和 PrintWindow 两种方式。
- 自动定位任务追踪区域；定位不成功时回退至任务栏区域。
- 使用 PaddleOCR 进行中文文字识别，并结合本地物品词表与已知 OCR 错别字进行校正。
- 支持手动识别、定时识别和全局快捷键触发。
- 支持录制单键或组合键快捷键，并可设置 0.5 至 60 秒的识别间隔。

## 系统要求

- Windows 10 或更高版本。
- 64 位 Python 3.11。
- 首次执行 OCR 时需要网络连接，以下载中文识别模型。

PaddlePaddle 2.6.2 不支持 Python 3.14；请使用 Python 3.11 安装依赖。

## 安装与运行

1. 下载或克隆本仓库。
2. 双击 [安装OCR依赖.cmd](scripts/安装OCR依赖.cmd)。脚本会在项目目录创建 `.venv` 并安装所需依赖。
3. 完成安装后，双击 [启动国令任务识别.cmd](scripts/启动国令任务识别.cmd)。
4. 在程序内选择目标游戏窗口和截图方式，点击“截取窗口”，再点击“识别并复制”。

识别成功后，所需物品名称会自动写入系统剪贴板。若启用实时识别，程序仅在任务区域发生明显变化时再次执行 OCR。

## 截图方式

`WGC（后台，高效）` 使用 Windows Graphics Capture 获取窗口画面。在目标窗口不支持、捕获会话关闭或限定时间内未取得画面时，程序会自动回退至 `PrintWindow`。

截图方式仅用于兼容性处理，不代表对游戏反作弊检测风险作出任何保证。请自行了解并遵守游戏规则及相关服务条款。

## 常见问题

**安装脚本提示找不到 Python 3.11**

请安装 64 位 Python 3.11，并确保命令 `py -3.11 --version` 可以正常执行。

**识别结果为空或不正确**

请确认任务追踪区域未被游戏内界面遮挡，并优先使用清晰、完整的游戏窗口画面。可尝试切换截图方式后重新截取。

**程序无法启动或识别失败**

请查看项目根目录的 `ocr_app.log`；安装过程日志保存在 `install_ocr.log`。提交 Issue 时请附上错误信息、系统版本和脱敏后的任务区域截图。
